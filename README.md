# 🌸 GlowUp — Portal de Autocuidado & Tecnologia (TCC)

Projeto completo do **TCC GlowUp**, composto por uma API RESTful em **Node.js + Express + TypeScript** com **MongoDB (Mongoose)**, documentação **Swagger** (OpenAPI 3.0), testes **Jest** + `mongodb-memory-server` e o **Front-end em React + Vite + Tailwind CSS**.

---

## 🛠️ Arquitetura do Projeto

- **Front-end**: React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons / FontAwesome
- **Back-end**: Node.js, Express, TypeScript, Mongoose (MongoDB)
- **Segurança**: Bcryptjs (Hash de senhas), JWT (JSON Web Tokens)
- **Documentação**: Swagger UI Express + JSDoc
- **Testes**: Jest + Supertest + MongoDB Memory Server

---

## 🚀 Como Executar o Projeto no VS Code

### 1. Iniciar o Back-end (API Node.js + MongoDB)
```bash
cd backend
npm install
npm run dev
```
- Servidor: `http://localhost:5000`
- Documentação Swagger: `http://localhost:5000/api-docs`

### 2. Rodar os Testes Automatizados no Back-end
```bash
cd backend
npm test
```

### 3. Iniciar o Front-end (React + Vite)
Abra um novo terminal no VS Code e execute:
```bash
cd frontend-react
npm install
npm run dev
```
- Aplicação React: `http://localhost:5173`
